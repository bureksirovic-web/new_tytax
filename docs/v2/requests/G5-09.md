- `.github/workflows/ci.yml`: new job `e2e-offline` (npm ci, `NEXT_PUBLIC_E2E_HOOKS=1 npx next build`,

  then `check-no-skips.mjs`). The dev-server `e2e` job now runs
  `--grep-invert '@sync|(^| )offline\.spec\.ts( |$)'`, which drops exactly the top-level `offline.spec.ts`
  (checked with `playwright test --list`: `sync-offline.spec.ts` and `zz/offline.spec.ts` stay in).

  "e2e-offline: SKIPPED: e2e/offline.spec.ts does not exist in this checkout." and records SKIP; when the file
  exists every step must pass (verified with a temporary spec: pass → `CI-LOCAL: PASS`, failing expect → `CI-LOCAL: FAIL`, rc 1).
