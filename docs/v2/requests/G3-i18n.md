## Page metadata keys (src/app/(app)/tools/**/page.tsx)

Server components cannot call `useLocale()`, so `metadata` reads `TOOLS_STRINGS.en` from `src/components/tools/tools-strings.ts` (the app's default locale). Titles reuse `tools_title`, `plate_title`, `rm_title`; descriptions:

| key | hr | en |
|---|---|---|
| tools_meta_desc | Kalkulatori ploča i 1RM-a | Plate and 1RM calculators |
| plate_meta_desc | Koje ploče staviti na svaku stranu šipke | Which plates to load on each side of the bar |
| rm_meta_desc | Procjena maksimuma za jedno ponavljanje iz serije | Estimate your one-rep max from a set |

Request: when G4's dictionary lands, move these into `src/lib/i18n` and build `metadata` (or `generateMetadata`) from it; `unit_kg` should follow G4's kg/lb setting.
