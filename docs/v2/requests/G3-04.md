# G3-04: foreign workout draft on the dashboard and in the profile switcher (owner: G4)

**What (Wave 0 review R04, S2):** the persisted workout draft (`useWorkoutStore`, localStorage
`tytax.workout-draft.v3`) carries `profileId`, and the active profile is device-level. After a profile switch
or delete in settings, the draft still belongs to the old profile. G3 now handles this on `/workout`,
`/workout/active`, `/workout/debrief` and `AddToWorkoutButton`; two G4 surfaces still treat any draft as the
active profile's.

**G3 API to use** (`@/hooks/use-workout`, `useWorkout()`):
- `foreignDraft: boolean`: true when a draft exists and `draft.profileId !== activeProfileId`.
- `draftOwner: Profile | null | undefined`: owner of a foreign draft (`null` = deleted).
- `switchToDraftOwner(): Promise<void>`: `repo.profiles.setActive(draft.profileId)`.
- Ready-made UI: `StartDraftCard` with `foreign={foreignInfo(workout)}` (`@/components/workout/start-draft-card`,
  `@/components/workout/foreign-draft`): owner name, `foreign-draft-switch`, confirmed `discard-workout`.
- Pure predicate for non-React code: `isForeignDraft(draft, activeProfileId)` from `@/stores/workout-orchestrator`.

**Requested changes:**
1. `src/app/(app)/dashboard/page-client.tsx`: where the dashboard shows "continue workout" for a draft, use
   `foreignDraft` and render `<StartDraftCard draft={draft} foreign={foreignInfo(workout)} onDiscard={...} />`
   (or the same texts) instead of a continue link.
2. `src/components/settings/family-section.tsx`:
   - Switching profile while a draft exists: tell the user the workout in progress stays with its profile
     (it is kept, not moved). No data change needed.
   - Deleting the profile that owns the draft: after confirm, also call `useWorkoutStore.getState().discard()`
     (the owner is gone, so the draft can never be saved: `finishWorkout` rejects a missing profile).
     Mention it in the delete confirm text when `draft.profileId === profileToDelete.id`.
3. i18n: reuse G3's `foreign_*` keys (docs/v2/requests/G3-i18n.md, start page table) when moving them into
   the shared dictionary.

**Why not in G3:** dashboard and settings are G4-owned files.
**Proof on the G3 side:** `e2e/workout-foreign-draft.spec.ts`, `src/hooks/__tests__/use-workout-foreign.test.ts`,
`src/components/workout/__tests__/wave0-followup-ui.test.tsx` ("R04: a draft of another profile").
