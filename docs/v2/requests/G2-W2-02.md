# G2-W2-02: bless `wipeAll()` on the Repository contract (to the contract owner / G5)

**Blocking:** no. Implemented as `RepositoryExt.wipeAll()` (`src/lib/db/repository.ts`); `getRepository()` is typed `RepositoryExt`; for a `Repository`-typed value use `getWipeAll(repo)` from `@/lib/db`.

## Proposed contract addition
```ts
export interface Repository {
  // ...
  /** Device wipe: clears every local table (all profiles, outbox, device meta). Queues nothing for sync. */
  wipeAll(): Promise<void>;
}
```

## Semantics (tested in src/lib/db/__tests__/w2-misc-wipe-equipment.test.ts)
- One rw transaction over every IndexedDB table, `meta` (active profile) and `syncQueue` included. Afterwards `profiles.getActiveId()` is `null`.
- Nothing is queued: a synced server copy is untouched (a wipe is "forget this device", not "delete my account").
- It never touches `localStorage`. The UI (G4) must clear its own keys after it resolves: the workout draft (G3's key), i18n/theme prefs, and reload.
- `resetAll()` stays test/e2e-only on the contract; `wipeAll` is the production path.
