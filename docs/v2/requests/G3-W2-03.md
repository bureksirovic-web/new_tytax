# G3-W2-03: render time-measured sets in History (to G4) and seed them in fixtures (to G5)

**From:** G3 (workout loop), hardening round 2, refuter finding 3 (+6). **Severity:** S2 (a finished hold
workout shows only zeros after the workout).

## What (measured at dc5b5d1, still true at 7669a4e)
A hold exercise finished with 45 s + 20 s renders in History as:
- detail `history-set`: `"1 0 kg × 0 reps"`, `"2 0 kg × 0 reps"` (`src/app/(app)/history/[id]/page-client.tsx`
  `SetLine` prints `set.kg × set.reps`, ignores `set.durationSeconds`);
- list item and detail header: `0 kg`, no hold total.
G3's debrief already shows the hold total (`debrief-hold`, `summary.timeSeconds`; e2e
`e2e/workout-wave2.spec.ts` "a finished 45 s hold comes back as the placeholder only").

## Data shape (contract `src/contracts/domain.ts`, unchanged)
`SetEntry.durationSeconds?: number` — whole seconds, 0..86 400 (G2 `assertDurationSeconds`).
A set is a time set when `durationSeconds > 0` (G1 `isTimeSet` from `@/lib/training`); for such a set
`kg` and `reps` are 0 (G3 writes kg 0 / reps 0 for time exercises) and meaningless.
Totals: `holdSeconds(sets)` / the per-log helper in `@/lib/training` (hold.ts) give the seconds held
(done working time sets only).

## Requested (G4)
1. `SetLine`: when `isTimeSet(set)`, render `m:ss` instead of `kg × reps`, e.g. `formatDuration` from
   `@/stores/measure` (`45 → "0:45"`, `125 → "2:05"`, `600 → "10:00"`), or an equivalent G4 helper with the
   same output. Keep RIR/PR/e1RM rules (time sets never have e1RM/PR).
2. History detail header and list item: show the log's hold total (`m:ss`) when > 0, beside/instead of
   `0 kg` volume for an all-hold workout.
3. e2e: finish a workout with a 45 s hold (through the UI, as `e2e/pr.spec.ts` does), open History →
   detail shows `0:45`.

## Requested (G5, fixtures)
`src/contracts/fixtures.ts` `SeedSetInput` has no `durationSeconds`, so `seedHistory` cannot create a time
set. Additive, optional: `SeedSetInput.durationSeconds?: number`, copied onto the built `SetEntry` in
`buildWorkoutLog`. Until then G3's e2e creates hold history through a real finished workout.
