# G5-10 → G3: workout store crashes `/dashboard` when site storage is blocked (src/stores, owned by G3)

**From:** G5, 2026-09-27 (verifier follow-up to the G4-01 SecurityError fix). **To:** G3 (`src/stores/**`); G5 applies it at INTEGRATION if still open. Non-blocking for G5.

## What
When the `window.localStorage` getter throws `SecurityError` (Safari private mode, blocked site data, some
embedded webviews), `createJSONStorage(() => localStorage)` in `src/stores/workout-store.ts` returns `undefined`.
zustand's `persist` then builds the store **without** its `persist` API, so `useWorkoutStore.persist` is
`undefined` and `useWorkoutHydrated()` throws in `subscribeHydration` / `getHydrated`. The route's error
boundary replaces the page.

## Evidence (2026-09-27, g5 worktree, `next start` on 3105, sync env on)
Chromium with an init script that makes the `localStorage` getter throw:

    /settings  OK   (ThemeProvider and LocaleProvider are guarded in v2-g5)
    /dashboard ERROR-BOUNDARY | … SOMETHING WENT WRONG Cannot read properties of undefined (reading 'onHydrate') Try again

Same code on `v2-g3` (lines 428, 441, 449, 460): `storage: createJSONStorage(() => localStorage)` and unguarded
`useWorkoutStore.persist.*` calls.

## Proposed change
Give `persist` a storage that never throws, falling back to memory for the page's lifetime:

```ts
function safeLocalStorage(): StateStorage {
  try {
    const s = window.localStorage;
    s.getItem('__probe');
    return s;
  } catch {
    const mem = new Map<string, string>();
    return {
      getItem: (k) => mem.get(k) ?? null,
      setItem: (k, v) => void mem.set(k, v),
      removeItem: (k) => void mem.delete(k),
    };
  }
}
// storage: createJSONStorage(safeLocalStorage),
```
Test: a store test that makes the getter throw with `Object.defineProperty(window, 'localStorage', { get() { throw … } })`
(pattern in `src/components/providers/__tests__/theme-provider.test.tsx`) and asserts `useWorkoutHydrated()`
renders and a draft can be started. Other `persist` stores in `src/stores/**` need the same storage.
