# G3-01: export Playwright `Page`/`Locator` types from `e2e/fixtures` (owner: G5)

**What:** `e2e/fixtures/index.ts` re-exports `test`, `expect` and seed types, but not `Page`/`Locator`.
The lint rule `no-restricted-imports` forbids `@playwright/test` in specs, so a spec with typed helpers cannot name those types.

**Workaround in G3 specs** (`e2e/pr.spec.ts`, `progression.spec.ts`, `tools.spec.ts`, `workout-loop.spec.ts`):
```ts
type Fixtures = Parameters<Parameters<typeof test.beforeEach>[1]>[0];
type Page = Fixtures['page'];
type Locator = ReturnType<Page['locator']>;
```

**Proposed fix:** add `export type { Page, Locator } from '@playwright/test';` to `e2e/fixtures/index.ts`; G3 then drops the aliases.
