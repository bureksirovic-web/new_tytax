# G5 i18n request: auth screens (AC13), account page and sync panel (AC12), app boot error

New keys used by `src/app/auth/login/*` (login screen and `?error=<code>` banner),
`src/app/auth/account/*`, `src/components/sync/*` (sync panel) and
`src/components/providers/app-bootstrap.tsx` (boot failure banner with retry, `app.boot.*`).
Until G4 merges them into `src/lib/i18n/modules/requests.ts`, `useAuthT()` (`src/lib/auth/use-auth-t.ts`)
detects the dictionary's key-echo fallback and renders the same values from `src/lib/auth/i18n.ts`
(`AUTH_STRINGS`). `src/lib/auth/__tests__/i18n.test.ts` fails if this table and `AUTH_STRINGS` drift.

Error keys follow `auth.error.<code>`; unknown codes render `auth.error.auth_failed`.
The dotted key style was specified by the G5 task brief; if G4 prefers the `auth_` snake_case prefix,
rename in `AUTH_STRINGS`, this table and the dictionary together at integration.
