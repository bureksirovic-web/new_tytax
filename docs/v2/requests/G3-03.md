# G3-03: e2e hooks G3 cannot add itself (owners: G4 dashboard testid, G5 e2e fixture)

**What:** two acceptance criteria are only partly proven end-to-end because the needed hooks live outside G3's files.

1. **AC4 program rotation (G4 + G5).** `e2e/program-rotation.spec.ts` creates the program with `tytax.seedProgram(...)`
   instead of installing the TYTAX 6-day preset through the programs UI, and asserts the predicted session only on
   `/workout` (`next-session-name`). The dashboard (`src/app/(app)/dashboard/page-client.tsx`) has no testid for its
   predicted next session, and the programs page has no stable testids for "install preset".
2. **AC6 PR persisted in prRecords (G5).** `e2e/pr.spec.ts` checks `log.prCount` and `set.isPR` only; the e2e fixture
   (`e2e/fixtures/seed.ts`) cannot read `prRecords`. The unit test `src/lib/db/__tests__/finish-workout.test.ts` covers it.

**Why not fixed in G3:** dashboard, programs UI and `e2e/fixtures/**` are outside G3 ownership.

**Proposed fix:**
- G4: `data-testid="dashboard-next-session"` on the dashboard prediction; `data-testid="install-preset"` (with
  `data-preset-id`) on the programs page preset install control.
- G5: add `listPRRecords(profileId)` to `window.__tytaxE2E` / the `tytax` fixture.
- Then G3's specs: install the preset through the UI and assert `dashboard-next-session`; in `pr.spec.ts` assert one
  `e1rm` and one `weight` record at 105 kg.
